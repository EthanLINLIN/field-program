# Field Program：面部情绪识别与 ESP32 控制

Field Program 是一个用于交互展示和开发实验的项目：它通过摄像头进行面部情绪识别，在本地网页呈现结果，并通过 ESP32 控制预设的实体装置效果。

## 快速开始

本目录包含两个相互独立的版本，选择与电脑操作系统对应的目录，并按其中的 README 安装：

如果使用具备文件和终端操作能力的 AI，可以将整个公开版目录交给它，并发送这句话：**请读取项目的 AI 安装与调试指南，自动识别我的操作系统，完成环境配置、依赖安装、模型下载和软件运行验证，并报告结果。**

- [Windows 版](Windows/README.md)
- [Linux 版](Linux/README.md)

对应的 AI 操作指南分别位于 [Windows/AGENTS.md](Windows/AGENTS.md) 和 [Linux/AGENTS.md](Linux/AGENTS.md)。

两个版本使用相同的情绪模型、界面、ESP32 固件和预设时序。FERPlus 权重不随仓库分发，首次运行从上游下载至项目目录外并校验哈希。Windows 使用全局小键盘热键；Linux 使用启动终端中的命令。在当前测试阶段，硬件流程由人工触发，尚未根据情绪识别结果自动选择动作。EEG 波形目前为仿真展示，系统已预留真实 EEG 设备数据接入的扩展接口，具体设备对接与功能集成有待后续开发。

这两个目录未包含原项目的 Python 虚拟环境、日志、人像、串口历史或 Git 历史。项目自有代码和经权利人确认的五项自有媒体素材采用 MIT 许可证。YuNet 附带上游许可证；FERPlus 模型的上游许可证标注仍需确认。公开发布前请阅读对应目录的 `THIRD_PARTY_NOTICES.md`。
